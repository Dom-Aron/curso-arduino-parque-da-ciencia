# Parque da Ciência Newton Freire Maia

## Aula 02 - Potenciômetro

**Ambiente:** Arduino IDE

### Experimento

Este experimento usa um potenciômetro como divisor de tensão e lê sua posição por uma entrada analógica do Arduino.

### O que se quer ensinar

- Ler sinais analógicos com o conversor ADC do Arduino.
- Entender a relação entre posição do potenciômetro, tensão e valor numérico lido.
- Usar o Monitor Serial para acompanhar dados em tempo real.
- Introduzir a ideia de sensores como fontes de informação para o programa.

### Ideia central

Uma grandeza física contínua pode ser convertida em números e usada pelo código para tomar decisões.
