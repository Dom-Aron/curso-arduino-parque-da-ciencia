# Parque da Ciência Newton Freire Maia

## Aula 03 - Lei de Ohm

**Ambiente:** Arduino IDE

### Experimento

Este experimento coleta dados elétricos para estudar a relação entre tensão, corrente e resistência em um circuito.

### O que se quer ensinar

- Investigar experimentalmente a Lei de Ohm.
- Relacionar medidas elétricas com modelos matemáticos.
- Registrar dados para posterior análise e construção de gráficos.
- Discutir limites de medição e cuidados com montagem elétrica.

### Ideia central

O Arduino pode ser usado como instrumento de aquisição de dados para transformar uma lei física em uma investigação experimental.
