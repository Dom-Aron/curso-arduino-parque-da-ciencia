# Parque da Ciência Newton Freire Maia

## Extra - Sensor LM35

**Ambiente:** Arduino IDE

### Experimento

Este conteúdo extra usa o sensor LM35 para medir temperatura com calibração simples, filtragem e histerese.

### O que se quer ensinar

- Aprofundar a leitura de sensores analógicos de temperatura.
- Aplicar média ou filtragem para reduzir ruído de leitura.
- Usar histerese para evitar oscilações em decisões automáticas.
- Relacionar calibração, estabilidade e confiabilidade da medida.

### Ideia central

Medir bem não é apenas ler um sensor: é tratar o sinal para que a informação faça sentido no experimento.
