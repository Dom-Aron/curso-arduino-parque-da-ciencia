# Parque da Ciência Newton Freire Maia

## Aula 10 - Aceleração gravitacional

**Ambiente:** Arduino IDE

### Experimento

Este experimento mede os tempos de passagem de uma esfera por sensores alinhados verticalmente para estimar a aceleração gravitacional.

### O que se quer ensinar

- Investigar queda livre com aquisição automática de dados.
- Relacionar posição, tempo, velocidade e aceleração.
- Discutir modelos de análise para movimentos acelerados.
- Perceber que a velocidade inicial pode influenciar o cálculo de `g`.

### Ideia central

O Arduino registra eventos rápidos com precisão suficiente para transformar a queda de um objeto em um conjunto de dados analisável.
