# Parque da Ciência Newton Freire Maia

## Aula 05 - Sensor Hall latch

**Ambiente:** Arduino IDE

### Experimento

Este experimento usa um sensor Hall para detectar a passagem de um campo magnético e contar eventos de rotação.

### O que se quer ensinar

- Compreender a detecção magnética por sensor Hall.
- Ler sinais digitais produzidos por sensores.
- Contar eventos e calcular grandezas associadas ao movimento circular.
- Relacionar frequência, período, RPM e velocidade angular.

### Ideia central

Eventos físicos discretos, como a passagem de um ímã, podem ser contados pelo Arduino para estudar movimento.
