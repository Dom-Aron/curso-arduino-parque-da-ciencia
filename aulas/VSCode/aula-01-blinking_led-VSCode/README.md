# Parque da Ciência Newton Freire Maia

## Aula 01 - LED piscante

**Ambiente:** VS Code

### Experimento

Este experimento faz um LED acender e apagar em intervalos regulares usando uma saída digital do Arduino.

### O que se quer ensinar

- Reconhecer a estrutura básica de um sketch Arduino, com `setup()` e `loop()`.
- Configurar um pino digital como saída.
- Controlar estados lógicos `HIGH` e `LOW`.
- Relacionar programação, tempo e observação física de um circuito simples.

### Ideia central

O LED piscante é o primeiro contato com automação: o programa passa a controlar um fenômeno visível no circuito.
