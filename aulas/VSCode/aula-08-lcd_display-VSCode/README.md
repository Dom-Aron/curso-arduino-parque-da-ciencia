# Parque da Ciência Newton Freire Maia

## Aula 08 - Display LCD

**Ambiente:** VS Code

### Experimento

Este experimento usa um display LCD 16x2 com interface I2C para mostrar textos, símbolos e pequenas animações.

### O que se quer ensinar

- Comunicar o Arduino com um módulo LCD via I2C.
- Posicionar textos em linhas e colunas do display.
- Criar caracteres customizados.
- Pensar em interfaces simples para apresentar informações de um experimento.

### Ideia central

Um display transforma o circuito em um instrumento mais autônomo, capaz de comunicar estados e resultados sem depender apenas do computador.
