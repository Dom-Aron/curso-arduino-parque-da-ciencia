# Parque da Ciência Newton Freire Maia

## Extra - Termodinâmica com LCD

**Ambiente:** VS Code

### Experimento

Este conteúdo extra exibe leituras de temperatura do LM35 em um display LCD 16x2 com interface I2C.

### O que se quer ensinar

- Integrar sensor analógico e display no mesmo experimento.
- Mostrar resultados localmente, sem depender apenas do Monitor Serial.
- Trabalhar atualização de tela, formatação de valores e clareza de apresentação.
- Reforçar conceitos de temperatura, leitura analógica e visualização de dados.

### Ideia central

O LCD torna a montagem mais parecida com um instrumento de laboratório, com leitura direta no próprio dispositivo.
