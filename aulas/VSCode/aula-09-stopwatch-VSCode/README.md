# Parque da Ciência Newton Freire Maia

## Aula 09 - Cronômetro

**Ambiente:** VS Code

### Experimento

Este experimento implementa um cronômetro com botões, sensores e display LCD para registrar tempos e voltas.

### O que se quer ensinar

- Medir intervalos de tempo usando `millis()`.
- Organizar estados de funcionamento, como parado, rodando e finalizado.
- Tratar botões e sensores sem travar o programa.
- Exibir resultados de medição em um display.

### Ideia central

Um bom instrumento de medida precisa controlar tempo, eventos de entrada e apresentação de dados de forma coordenada.
