# Parque da Ciência Newton Freire Maia

## Aula 07 - Driver com transistor e relé

**Ambiente:** VS Code

### Experimento

Este experimento aciona uma carga por meio de um transistor BC548 e um relé, usando o Arduino apenas como circuito de controle.

### O que se quer ensinar

- Entender por que um pino do Arduino não deve alimentar cargas diretamente.
- Usar transistor como chave eletrônica.
- Compreender o papel do relé, do resistor de base, do resistor de pull-down e do diodo de proteção.
- Separar circuito de controle e circuito de potência.

### Ideia central

O Arduino pode comandar cargas maiores com segurança quando usa uma interface de acionamento adequada.
