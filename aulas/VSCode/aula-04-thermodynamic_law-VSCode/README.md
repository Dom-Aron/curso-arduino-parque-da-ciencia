# Parque da Ciência Newton Freire Maia

## Aula 04 - Termodinâmica sem LCD

**Ambiente:** VS Code

### Experimento

Este experimento lê sensores LM35 para acompanhar temperaturas e observar processos de troca térmica.

### O que se quer ensinar

- Medir temperatura com sensores analógicos.
- Converter leitura ADC em tensão e depois em temperatura.
- Observar equilíbrio térmico e variações de temperatura ao longo do tempo.
- Usar Monitor Serial e Plotter Serial como ferramentas de visualização.

### Ideia central

Uma medida de temperatura pode ser acompanhada continuamente, permitindo discutir fenômenos térmicos com dados reais.
